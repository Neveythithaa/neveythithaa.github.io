# Neveythithaa S — VLSI Design Portfolio

Responsive personal portfolio for an M.Tech VLSI Design student, highlighting ASIC Physical Design interests, RTL-to-GDSII implementation, low-power VLSI projects, embedded-system projects, research, skills and education.

## Published website

https://neveythithaa.github.io/

## Repository structure

```text
.
├── index.html
├── README.md
└── assets/
    ├── Neveythithaa_S_Resume.pdf
    ├── lora_hardware_setup.webp
    ├── lora_transmitter_circuit.webp
    ├── lora_receiver_circuit.webp
    ├── flood_alert_circuit.webp
    ├── flood_alert_hardware_demo.webp
    └── flood_alert_thingspeak_demo.webp
```

The `assets/` files above are required by the current HTML. Upload them into the repository's `assets/` directory to enable the résumé download and all project-gallery images.

## Preview locally

Open `index.html` in a current desktop or mobile browser. Keep the `assets/` directory alongside it.

## Responsive layout

The page includes desktop/laptop navigation, a collapsible menu for smaller screens, and responsive project, skills, education and contact sections.

## Project result interpretation

The 25% power reduction is the reported result for the evaluated clock-gated project setup (168 µW to 126 µW). Results depend on workload, design constraints and the implementation flow; they are not a universal guarantee.
